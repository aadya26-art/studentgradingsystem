Problem Statement:-
Educational institutions often require lightweight, efficient systems to calculate student grades, track performance analytics, and manage academic records without relying on bloated software or manual entry.

Project Scope:-
This project provides a automated solution to process student records across five core subjects (Maths, Physics, Programming, English, Chemistry). It offers data validation, automated roll number generation, grade assignment, and statistical reports.

Target Users:-
- Instructors and Course Coordinators
- Academic Administrators

Key Features:-
1. Student CRUD operations (Add, Read, Update, Delete).
2. Mark sheet and summary generation.
3. Class analytics (Grade distribution, Pass/Fail counts, Topper identification, Class statistics).
