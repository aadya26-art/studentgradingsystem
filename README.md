# Student Grading System
Project Summary:-
This project is created to have a curated way of presenting and processing the grading system of a student.
Course:CSE1021 - Introduction to Problem Solving and Programming
Author:Aadya Singh 26BCE11260

Features:-
*Student Record Management:* Add, update, and delete student details.
*Grade & Performance Analytics:* Automatically calculate averages, assign letter grades, and track pass/fail status.
*Reporting:* View class toppers, grade distributions, sorted/unique averages, and K-th smallest averages.
*Sample Data Loader:* Load dummy data instantly for quick demonstration.
